# Changelog

## 1.0.0

- Detect native and Flatpak Chromium-based browsers, with optional custom executable, user-data directory and Python interpreter preferences.
- Create, edit, open and remove desktop launchers while sharing the selected browser profile's sign-ins.
- Infer Dashboard Icons artwork or accept custom icons with consistent dock padding.
- Offer guided PWA installation with profile-specific registration checks and app-mode fallback.
- Check active Flatpak sandbox permissions and explain when a full browser restart is required.
- Support optional borderless GTK/WebKit windows with separate persistent sessions.
- Preserve earlier launcher identities and pins while refreshing portable helper paths.
- Package the PWA helper during dependency installation so direct store builds include it.
