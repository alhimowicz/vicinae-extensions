# Changelog

## 1.0.0

- Add a native Upcoming section above Favorites, showing actual event titles, start times, and countdowns.
- Show a live Next Event preview and a searchable seven-day agenda from Evolution Data Server.
- Open meeting links with Enter, with a picker for ambiguous links and details when none exists.
- Choose calendars and retain cached events when a calendar is unavailable.
- Sync connected calendars on refresh, with progress and completion indications.
